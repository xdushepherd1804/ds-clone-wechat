## 目标

实现登录、注册、忘记密码页面的 UI 和交互逻辑，完成 Token 存储和自动登录功能。

## 功能需求

### 页面列表

- **登录页**: 手机号/邮箱 + 密码，登录按钮
- **注册页**: 昵称 + 手机号 + 密码 + 确认密码
- **忘记密码**: 手机验证码 + 新密码 (开发阶段简化)

### 交互逻辑

```
登录流程:
  输入凭证 → 表单校验 → 调用 /api/auth/login
  → 成功: 存储 token (localStorage) → 跳转到 /chat
  → 失败: 显示错误提示

注册流程:
  输入信息 → 表单校验 → 调用 /api/auth/register
  → 成功: 自动登录 → 跳转到 /chat
  → 失败: 显示错误提示

自动登录:
  App 启动 → 检查 localStorage 有无 token
  → 有: 调用 /api/users/me 验证 → 有效则进入主界面
  → 无/过期: 跳转 /login
```

### UI 设计

- 居中卡片式布局
- 微信绿主题色 (#07C160)
- 响应式设计 (移动端适配)
- 输入校验实时反馈
