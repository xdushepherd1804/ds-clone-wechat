## 目标

编写端到端浏览器自动化测试，覆盖核心用户流程。

## 测试工具

- Playwright (推荐，支持多浏览器)
- 测试用例使用 BDD 风格描述

## 测试场景

### 注册与登录

```
Scenario: 新用户注册
  Given 用户在注册页面
  When 填写有效信息并提交
  Then 自动登录并跳转到聊天页面

Scenario: 错误密码登录
  Given 用户在登录页面
  When 输入错误的密码
  Then 显示"密码错误"提示
```

### 完整聊天流程

```
Scenario: 好友聊天
  Given 用户 A 已登录
  And 用户 B 在另一个浏览器窗口登录
  When A 搜索并添加 B 为好友
  And B 接受好友申请
  And A 打开与 B 的会话
  And A 发送文本消息 "Hello"
  Then B 的消息列表实时显示 "Hello"
  And B 发送回复 "Hi there"
  Then A 的消息列表实时显示 "Hi there"
```

### 群聊功能

```
Scenario: 群聊操作
  Given 用户 A 已登录
  When A 创建群聊 "技术交流群"
  And A 邀请 B 和 C
  Then B 和 C 的会话列表出现"技术交流群"
  When B 在群内 @A 并发送消息
  Then A 收到 @提醒
```

### 朋友圈

```
Scenario: 发布和互动
  Given 用户 A 已登录
  When A 发布朋友圈 "今天天气真好" 并附图
  Then 好友 B 的时间线中出现该动态
  When B 点赞并评论 "确实！"
  Then A 看到 B 的点赞和评论
```
