## 目标

实现用户离线时的推送通知，集成 APNs (iOS) 和 FCM (Android/Web)。

## 功能需求

### 推送场景

- 新消息推送: "张三: 你好"
- 好友申请推送: "李四 请求加你为好友"
- 群@推送: "张三 在群聊中@了你"
- 通话邀请推送: "张三 邀请你语音通话"

### 推送流程

```
消息到达 → Message Service → 查 Redis，用户离线
  → 写入推送队列 → Push Worker
  → 查用户设备注册表 (device_tokens 表)
  → 调用 APNs/FCM API → 发送推送
```

### 设备注册

```
POST /api/push/register-device
  { platform: 'ios'|'android'|'web', device_token: 'xxx' }
DELETE /api/push/unregister-device
```

### 推送服务封装

```typescript
interface PushProvider {
  send(userId: string, payload: PushPayload): Promise<void>;
  sendToMany(userIds: string[], payload: PushPayload): Promise<void>;
}

class FCMProvider implements PushProvider { ... }
class APNsProvider implements PushProvider { ... }
class MockProvider implements PushProvider { ... }  // 开发阶段
```
