## 目标

构建统一的 API 网关，负责请求路由、认证鉴权、限流、日志、CORS、请求/响应转换。

## 功能需求

### 核心能力

- **路由转发**: 根据 path 前缀将请求转发到对应微服务
- **JWT 鉴权**: 验证 Token，注入用户上下文到 Header
- **限流**: 基于 IP/用户 ID 的令牌桶限流
- **日志**: 请求日志 (method, path, status, latency)
- **CORS**: 跨域支持配置
- **错误处理**: 统一错误响应格式
- **健康检查**: /health 端点

### 路由表

```
/api/auth/*        → auth-service:3001
/api/users/*       → auth-service:3001
/api/messages/*    → message-service:3002
/api/contacts/*    → contact-service:3003
/api/groups/*      → group-service:3004
/api/files/*       → file-service:3005
/api/moments/*     → moments-service:3006
/ws                → ws-gateway:3007
```

### 中间件链

```
Request → Logger → CORS → RateLimiter → Auth(JWT) → Router → Service
```

1. 认证请求正确路由到 Auth Service
2. 无 Token 请求返回 401
3. 限流触发后返回 429
4. 所有请求有日志输出
5. 不存在的路由返回 404
