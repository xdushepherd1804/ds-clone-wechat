## 目标

实现朋友圈动态发布、时间线聚合、点赞、评论、可见性控制等社交功能。

## 功能需求

### API 接口

```
POST   /api/moments              - 发布动态
GET    /api/moments/timeline      - 好友动态时间线 (分页)
GET    /api/moments/user/:uid     - 某用户动态列表
GET    /api/moments/:id           - 动态详情
DELETE /api/moments/:id           - 删除动态
POST   /api/moments/:id/like      - 点赞/取消点赞
POST   /api/moments/:id/comments  - 发表评论
DELETE /api/moments/:id/comments/:cid - 删除评论
```

### 时间线聚合

```
好友动态时间线:
  SELECT * FROM moments
  WHERE user_id IN (SELECT contact_id FROM contacts WHERE user_id = ?)
    AND visibility != 'private'
  ORDER BY created_at DESC
  LIMIT 20 OFFSET ?

缓存策略:
  - Redis ZSET: timeline:{uid} 存储好友最近动态 ID
  - 发布动态时推送到所有好友的时间线缓存
  - 删除好友时从缓存中清除其动态
```

### 可见性控制

- public: 所有人可见
- friends: 仅好友可见
- private: 仅自己可见

### 点赞与评论

- 点赞: Toggle 模式，重复点击取消
- 评论: 支持回复评论 (盖楼)
- 仅动态发布者可删除评论
- 仅评论发布者可删除自己的评论
