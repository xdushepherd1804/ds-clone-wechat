## 目标

实现文件上传、图片压缩缩略、文件下载、访问控制等文件管理能力。

## 功能需求

### API 接口

```
POST   /api/files/upload           - 上传文件 (multipart)
GET    /api/files/:id              - 下载/查看文件
GET    /api/files/:id/thumbnail    - 获取缩略图
DELETE /api/files/:id              - 删除文件
POST   /api/files/upload-chunk     - 分片上传 (大文件)
POST   /api/files/merge-chunks     - 合并分片
```

### 图片处理

- 原图存储 + 自动生成缩略图 (sharp / imagemagick)
- 缩略图尺寸: 200x200 (小), 800x800 (大)
- 格式: 保持原格式或统一转 WebP
- 大小限制: 原图 10MB, 文件 100MB

### 存储策略

- 本地开发: 存储到 `uploads/` 目录
- 生产环境: MinIO / S3 兼容对象存储
- 文件命名: `{type}/{date}/{uuid}.{ext}`
- 访问控制: 私有文件需 Token 鉴权，公开文件直接访问

### 文件类型校验

```
图片: jpg, jpeg, png, gif, webp, svg
视频: mp4, mov, avi
音频: mp3, wav, aac, ogg
文件: pdf, doc, docx, xls, xlsx, ppt, txt, zip
```
