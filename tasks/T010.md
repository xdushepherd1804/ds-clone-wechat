## 目标

实现群组创建、解散、成员管理、群公告、@提醒、群角色权限等群聊功能。

## 功能需求

### API 接口

```
POST   /api/groups/create          - 创建群组
DELETE /api/groups/:id             - 解散群组 (群主)
PUT    /api/groups/:id             - 编辑群信息
GET    /api/groups/:id             - 群详情
GET    /api/groups/:id/members     - 群成员列表
POST   /api/groups/:id/members     - 邀请成员
DELETE /api/groups/:id/members/:uid - 踢出成员
POST   /api/groups/:id/join        - 申请加入
PUT    /api/groups/:id/join/:uid   - 审批加入
POST   /api/groups/:id/quit        - 退出群组
PUT    /api/groups/:id/announcement - 设置群公告
PUT    /api/groups/:id/members/:uid/role - 设置成员角色
PUT    /api/groups/:id/mute/:uid   - 禁言成员
```

### 群角色与权限

| 角色 | 权限 |
|------|------|
| owner | 解散群、设置管理员、踢人、群公告、编辑群信息 |
| admin | 踢人、审批加入、群公告 |
| member | 发消息、邀请好友、退群 |

### @提醒

- 消息体包含 `@mentions: [uid1, uid2]` 字段
- @所有人仅群主/管理员可用
- 被@用户收到特殊推送

### 群成员缓存

- Redis Set: `group:members:{group_id}` 存储成员列表
- 成员变动时更新缓存
- 消息推送时从缓存读取成员列表
