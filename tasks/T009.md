## 目标

实现好友添加/删除、联系人列表、备注、标签管理、黑名单等通讯录核心功能。

## 功能需求

### API 接口

```
POST   /api/contacts/request      - 发送好友申请
PUT    /api/contacts/accept/:id    - 接受好友申请
DELETE /api/contacts/:uid          - 删除好友
GET    /api/contacts/list          - 好友列表 (含在线状态)
PUT    /api/contacts/:uid/remark   - 修改备注
PUT    /api/contacts/:uid/tags     - 设置标签
GET    /api/contacts/requests      - 好友申请列表
POST   /api/contacts/block/:uid    - 拉黑用户
DELETE /api/contacts/block/:uid    - 取消拉黑
GET    /api/contacts/search?q=     - 搜索联系人
```

### 好友添加流程

```
A 申请加 B → 写入 friends_requests 表 (status=pending)
B 查看申请 → 接受 → 写入 contacts 表 (双向)
B 拒绝 → 更新 friends_requests 表 (status=rejected)

contacts 表双向存储:
  user_id=A, contact_id=B, remark=xxx
  user_id=B, contact_id=A, remark=yyy
```

### 在线状态

- 通过 Redis `user:online:{uid}` 判断在线
- 好友列表附带在线状态字段
- 好友上线/下线推送 (通过 WS)
