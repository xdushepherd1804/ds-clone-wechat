## 目标

定义全栈共享的 TypeScript 类型、常量、工具函数、错误码、API 契约。前后端基于统一的类型定义进行开发。

## 内容

### 共享类型 (packages/shared)

```
types/
  user.ts       - 用户类型
  message.ts    - 消息类型 (MsgType, Message, Conversation)
  contact.ts    - 通讯录类型
  group.ts      - 群类型
  moments.ts    - 朋友圈类型
  api.ts        - API 请求/响应泛型
  ws.ts         - WebSocket 消息协议

constants/
  error-codes.ts  - 错误码枚举
  msg-types.ts    - 消息类型常量
  config.ts       - 公共配置

utils/
  id-generator.ts  - ID 生成
  time.ts          - 时间格式化
  crypto.ts        - 加密工具
  validator.ts     - 输入校验

proto/
  message.proto    - Protobuf 消息定义 (可选)
```

### API 契约

定义统一的 API 响应格式：

```typescript
interface ApiResponse<T> {
  code: number;
  message: string;
  data: T;
  timestamp: number;
}
```

### WebSocket 协议

```typescript
// 上行 (Client → Server)
type WSRequest = {
  cmd: 'send_msg' | 'ack_msg' | 'heartbeat' | 'typing' | 'read';
  seq: number;
  body: Record<string, unknown>;
};

// 下行 (Server → Client)
type WSResponse = {
  cmd: 'new_msg' | 'ack' | 'error' | 'typing' | 'online_status';
  seq: number;
  body: Record<string, unknown>;
};
```
