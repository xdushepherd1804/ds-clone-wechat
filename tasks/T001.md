## 目标

搭建 monorepo 项目结构，统一全栈项目的目录组织、包管理、代码规范、容器化基础。

## 技术选型

- 包管理: pnpm workspace (monorepo)
- 后端: Go (Gin) 或 Node.js (NestJS) — 需确认
- 前端: React 18 + TypeScript + Vite
- 容器化: Docker + Docker Compose
- 代码规范: ESLint + Prettier + EditorConfig
- Git Hooks: Husky + lint-staged

## 目录结构设计

```
wechat-clone/
├── packages/
│   ├── shared/          # 共享类型、常量、工具
│   ├── server-auth/     # 认证服务
│   ├── server-message/  # 消息服务
│   ├── server-gateway/  # API/WS 网关
│   ├── server-contact/  # 通讯录服务
│   ├── server-group/    # 群聊服务
│   ├── server-file/     # 文件服务
│   ├── server-moments/  # 朋友圈服务
│   └── web/             # 前端 React App
├── docker/
│   ├── docker-compose.yml
│   └── Dockerfile.*
├── scripts/             # 构建/部署脚本
├── docs/                # 文档
├── pnpm-workspace.yaml
├── package.json
└── tsconfig.base.json
```

## 测试标准

1. `pnpm install` 成功安装所有依赖
2. `docker compose up -d` 启动所有基础服务
3. ESLint 可正常执行
4. 目录结构符合设计方案
