## 目标

实现完整的 Docker 容器化，支持一键启动全栈服务。

## 功能需求

### Docker Compose 编排

```yaml
services:
  postgres:
    image: postgres:16-alpine
  redis:
    image: redis:7-alpine
  mongodb:
    image: mongo:7
  auth-service:
    build: ./packages/server-auth
  message-service:
    build: ./packages/server-message
  contact-service:
    build: ./packages/server-contact
  group-service:
    build: ./packages/server-group
  file-service:
    build: ./packages/server-file
  moments-service:
    build: ./packages/server-moments
  ws-gateway:
    build: ./packages/server-gateway/ws
  api-gateway:
    build: ./packages/server-gateway
  web:
    build: ./packages/web
  nginx:
    image: nginx:alpine
    # 反向代理前端 + API
```

### 各服务 Dockerfile

- 后端: Multi-stage build (Go: scratch / Node: alpine)
- 前端: Nginx 静态资源 + SPA 路由
- 健康检查 (HEALTHCHECK)

### 环境配置

- 通过环境变量区分环境
- 敏感信息通过 Docker secrets 或 .env 文件
- 数据持久化 (volumes)

### 脚本

```
./scripts/dev-up.sh          # 开发环境启动
./scripts/dev-down.sh        # 停止
./scripts/prod-build.sh      # 生产构建
./scripts/db-migrate.sh      # 数据库迁移
./scripts/db-seed.sh         # 数据填充
```

1. `docker compose up -d` 一键启动全部服务
2. 前端可访问，API 可调用
3. WebSocket 连接正常
4. 数据库数据重启后不丢失
5. 健康检查端点正常
