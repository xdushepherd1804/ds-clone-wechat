## 目标

实现消息全文搜索、联系人搜索、聊天记录搜索等功能。

## 功能需求

### 搜索范围

- 消息内容 (文本消息)
- 联系人 (昵称、备注)
- 群聊名称
- 文件名称

### 搜索 API

```
GET /api/search/messages?q=keyword&conv_id=&page=&size=
GET /api/search/contacts?q=keyword
GET /api/search/groups?q=keyword
GET /api/search/all?q=keyword     → 聚合搜索
```

### 实现方案

- 轻量方案: PostgreSQL full-text search (tsvector)
- 进阶方案: Elasticsearch (生产推荐)
- 索引策略: 消息内容分词索引，按会话过滤
- 搜索结果高亮关键词

### 搜索UI交互

- 全局搜索入口 (顶部搜索框)
- 搜索结果分类展示 (消息/联系人/群聊/文件)
- 点击消息结果跳转到对应会话位置
- 搜索历史记录
