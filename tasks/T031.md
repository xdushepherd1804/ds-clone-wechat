## 目标

对核心服务进行性能基准测试，识别瓶颈，设定性能基线。

## 测试场景

### WebSocket 连接压测

```
测试工具: k6 / artillery / autocannon
场景:
  - 逐步增加到 10,000 并发 WebSocket 连接
  - 观察内存、CPU 使用率
  - 测量连接建立延迟
目标:
  - 10K 连接建立 < 200ms (p99)
  - 内存 < 2GB
```

### 消息吞吐压测

```
场景:
  - N 个用户同时发送消息
  - 测量消息端到端延迟
目标:
  - 1000 msg/s 吞吐下延迟 < 500ms (p99)
  - 消息丢失率 = 0%
```

### API 压测

```
场景:
  - 登录接口: 1000 req/s
  - 好友列表: 500 req/s
  - 时间线: 500 req/s
目标:
  - p99 < 200ms
  - 错误率 < 0.1%
```
