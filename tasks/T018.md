## 目标

实现前端 WebSocket 客户端，完成连接管理、心跳维持、消息收发、断线重连、状态同步。

## 功能需求

### 连接管理

```typescript
class WSClient {
  connect(token: string): void;
  disconnect(): void;
  reconnect(): void;
  send(cmd: string, body: unknown): Promise<void>;
  on(cmd: string, handler: (data) => void): void;
  off(cmd: string, handler: (data) => void): void;
  isConnected(): boolean;
}
```

### 心跳与重连

- 连接成功后每 30s 发送 Ping
- 60s 内未收到 Pong 视为断线
- 指数退避重连: 1s, 2s, 4s, 8s, 16s, 最大 30s
- 页面不可见时暂停重连 (visibilitychange)
- Token 过期后停止重连，跳转登录

### 消息协议

```typescript
// 接收消息处理
client.on('new_msg', (msg: WSMessage) => {
  chatStore.addMessage(msg.conversationId, msg);
  // 如果当前不在该会话，增加未读计数
});

client.on('online_status', ({ uid, online }) => {
  contactStore.updateOnlineStatus(uid, online);
});

client.on('typing', ({ uid, conversationId }) => {
  chatStore.setTyping(conversationId, uid);
});

client.on('read_ack', ({ conversationId, msgId }) => {
  chatStore.updateReadStatus(conversationId, msgId);
});
```

### 状态同步

- 连接建立后同步所有会话的未读计数
- 重连成功后补拉期间错过的消息
- 网络状态变化时更新 UI 状态栏
