## 目标

实现拼手气红包和普通红包的发送、领取、过期退还功能。

## 功能需求

### 红包类型

- **普通红包**: 固定金额，每人领取相同金额
- **拼手气红包**: 总金额固定，每人随机领取 (二倍均值算法)

### 红包流程

```
发红包:
  Sender → 设置金额、个数、祝福语
  → 调用支付接口 (开发阶段模拟)
  → 红包消息发送到会话

领红包:
  Receiver → 点击红包消息
  → 检查是否已领取、是否已抢完、是否过期
  → 随机计算金额 (拼手气)
  → 写入 red_packet_records 表
  → 更新红包剩余状态 (Redis)
  → 金额入账 (模拟)

过期退还:
  24h 后未领完 → 剩余金额退还发送者
  → 红包状态更新为 expired
```

### API

```
POST   /api/redpacket/send       - 发红包
POST   /api/redpacket/open/:id   - 领红包
GET    /api/redpacket/:id        - 红包详情 (领取列表)
GET    /api/redpacket/history    - 红包记录
```

### 数据结构

```sql
CREATE TABLE red_packets (
  id UUID PRIMARY KEY,
  sender_id UUID NOT NULL,
  conversation_id VARCHAR(100),
  total_amount DECIMAL(10,2),  -- 总金额 (分)
  total_count INT,              -- 总个数
  remaining_count INT,          -- 剩余个数
  remaining_amount DECIMAL(10,2), -- 剩余金额
  type VARCHAR(20),             -- 'fixed' | 'random'
  blessing VARCHAR(100),
  status VARCHAR(20),           -- 'active' | 'finished' | 'expired'
  expired_at TIMESTAMP,
  created_at TIMESTAMP
);

CREATE TABLE red_packet_records (
  id UUID PRIMARY KEY,
  packet_id UUID REFERENCES red_packets(id),
  user_id UUID NOT NULL,
  amount DECIMAL(10,2),
  created_at TIMESTAMP
);
```
