## 目标

实现通讯录页面，包含好友列表、搜索、联系人详情、好友申请管理、在线状态展示。

## 功能需求

### 页面结构

```
通讯录页面 (/contacts)
├── 搜索栏 (按昵称/备注搜索)
├── 新朋友 (好友申请入口，红点提示)
├── 群聊 (已加入群聊列表)
├── 好友列表 (按字母排序)
│   ├── 好友项 (头像 + 昵称/备注 + 在线状态)
│   └── 字母索引导航
└── 联系人详情 (弹窗/侧边栏)
    ├── 头像 + 昵称 + 备注
    ├── 标签管理
    ├── 发消息按钮
    └── 更多 (删除好友、拉黑)
```

### 交互逻辑

- 点击好友项 → 跳转到聊天 /chat/:conv_id
- 搜索支持模糊匹配昵称和备注
- 好友申请红点未读数
- 在线状态: 绿色圆点 (在线) / 灰色圆点 (离线)
- 长按/右键好友项可弹出操作菜单

### 好友申请管理

- 申请列表: 头像 + 昵称 + 申请理由 + 接受/拒绝按钮
- 接受后自动刷新好友列表
- 拒绝后从申请列表移除
