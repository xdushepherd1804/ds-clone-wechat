## 目标

实现二维码生成 (用户名片、群邀请) 和二维码扫描读取功能。

## 功能需求

### 二维码生成

- 用户名片二维码: 包含 uid，扫码可添加好友
- 群邀请二维码: 包含 group_id + 邀请码，扫码加入群
- 登录二维码 (可选): 扫码登录 Web 端
- 二维码美化: 中间嵌入头像/Logo

### 二维码扫描

- 使用浏览器 Camera API 或 qrcode 库
- 识别二维码内容
- 跳转到相应页面 (添加好友/加入群聊)

### API

```
GET  /api/qrcode/user-card      - 生成用户名片二维码 (PNG)
GET  /api/qrcode/group-invite   - 生成群邀请二维码
POST /api/qrcode/scan-result    - 处理扫码结果
```

## 交付物

- [ ] QRCode 生成服务 (qrcode 库)
- [ ] QRCode 扫描组件 (jsQR / html5-qrcode)
- [ ] 用户名片二维码显示页面
- [ ] 扫码添加好友流程

## 测试标准

1. 生成的二维码可被标准扫码工具识别
2. 扫码后正确跳转添加好友页面
3. 群邀请二维码扫码后可加入群
