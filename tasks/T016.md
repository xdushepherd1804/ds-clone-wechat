## 目标

实现一对一聊天界面，包括消息列表、输入框、消息类型渲染、已读状态、撤回等核心聊天体验。

## 功能需求

### 页面布局

```
┌──────────────────────────────────────┐
│  导航栏: 头像 | 对方昵称 | 操作按钮  │
├──────────────────────────────────────┤
│                                      │
│         消息列表 (虚拟滚动)           │
│   - 文本消息 (自己/对方 气泡)        │
│   - 图片消息 (缩略图 → 大图预览)     │
│   - 语音消息 (波形 + 时长)           │
│   - 视频消息 (封面 → 播放)           │
│   - 文件消息 (图标 + 文件名 + 大小)  │
│   - 系统消息 (居中灰色文字)          │
│   - 时间分割线                       │
│   - 已读/未读状态                    │
│                                      │
├──────────────────────────────────────┤
│  输入区域                             │
│  [表情] [图片] [文件] [语音]        │
│  ┌──────────────────────────────┐    │
│  │  文本输入框 (多行自适应)      │    │
│  └──────────────────────────────┘    │
│                        [发送 按钮]   │
└──────────────────────────────────────┘
```

### 消息气泡样式

- 自己的消息: 右侧绿色气泡
- 对方的消息: 左侧白色气泡
- 图片消息: 圆角缩略图，点击全屏预览
- 语音消息: 可播放的音频条 (时长标注)
- 已读回执: 消息下方灰色 ✓/✓✓ (已读变绿)

### 核心交互

- 发送文本消息 (Enter 发送，Shift+Enter 换行)
- 发送图片 (粘贴/拖拽/选择文件)
- 发送文件 (文件选择器)
- 语音录制 (长按录音按钮)
- 表情面板 (emoji 选择器)
- 点击图片全屏预览 (支持缩放、旋转)
- 撤回消息 (2分钟内，右键菜单)
- 消息时间戳显示
- 上拉加载历史消息
- 新消息自动滚动到底部

### Hooks

```typescript
useMessages(conversationId)     // 消息列表管理
useSendMessage(conversationId)  // 发送消息
useTypingIndicator(conversationId)  // 对方正在输入
useMessageRead(conversationId)  // 已读状态
```
