## 目标

初始化 React + TypeScript 前端项目，配置路由、状态管理、HTTP 客户端、WebSocket 客户端基础。

## 技术选型

- 框架: React 18 + TypeScript
- 构建: Vite
- 路由: React Router v6
- 状态管理: Zustand
- HTTP: Axios (拦截器 + Token 注入)
- UI 库: Ant Design 5
- 样式: CSS Modules / Tailwind CSS
- 国际化: i18next (可选，先硬编码中文)

## 目录结构

```
packages/web/
├── src/
│   ├── api/            # API 请求封装
│   │   ├── client.ts   # Axios 实例 + 拦截器
│   │   ├── auth.ts     # 认证 API
│   │   ├── contact.ts  # 通讯录 API
│   │   ├── message.ts  # 消息 API
│   │   └── group.ts    # 群聊 API
│   ├── components/     # 通用组件
│   ├── pages/          # 页面组件
│   ├── hooks/          # 自定义 Hooks
│   ├── store/          # Zustand Stores
│   ├── types/          # 前端类型 (引用 shared)
│   ├── utils/          # 工具函数
│   ├── ws/             # WebSocket 客户端
│   ├── App.tsx
│   └── main.tsx
├── index.html
├── vite.config.ts
└── package.json
```

## 路由设计

```
/                → 重定向到 /chat
/login           → 登录页
/register        → 注册页
/chat            → 消息主页 (Outlet)
/chat/:conv_id   → 具体会话
/contacts        → 通讯录
/contacts/:uid   → 联系人详情
/moments         → 朋友圈
/me              → 我的
```
