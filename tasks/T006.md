## 目标

建立统一的配置管理和服务注册发现机制，支持多环境配置和服务间通信。

## 功能需求

### 配置管理

- 环境变量 + YAML 配置文件
- 多环境: development, staging, production
- 敏感信息加密/脱敏
- 配置热加载 (开发阶段可选)

### 服务发现

- 服务注册表 (可用简单的 JSON 配置代替)
- 健康检查机制
- 服务地址解析

### 配置结构

```yaml
# config/default.yaml
app:
  name: wechat-clone
  env: development

gateway:
  port: 3000

services:
  auth:
    host: localhost
    port: 3001
  message:
    host: localhost
    port: 3002

database:
  postgres:
    host: localhost
    port: 5432
    database: wechat
  redis:
    host: localhost
    port: 6379
  mongodb:
    uri: mongodb://localhost:27017/wechat

jwt:
  secret: ${JWT_SECRET}
  access_expire: 15m
  refresh_expire: 7d
```
