## 目标

实现表情面板 (Emoji Picker) 和自定义表情贴图管理、收藏功能。

## 功能需求

### Emoji 表情

- 内置标准 Emoji 表情集 (Unicode 13.0+)
- 分类: 表情、自然、食物、活动、旅行、物体、符号、旗帜
- 最近使用记录 (本地存储)
- 表情搜索

### 自定义贴图

- 用户可上传自定义贴图
- 贴图收藏/取消收藏
- 贴图包管理
- 贴图缩略图显示

### 表情面板UI

```
┌──────────────────────────────┐
│  [😀] [🌿] [🍔] [⚽] [✈️]  │ ← 分类标签
├──────────────────────────────┤
│  😀 😃 😄 😁 😅 😂 🤣     │
│  😊 😇 🙂 🙃 😉 😌 😍     │
│  🥰 😘 😗 😙 😚 😋 😛    │
│  ...                        │
├──────────────────────────────┤
│  [最近] [收藏] [自定义]     │ ← 底部
└──────────────────────────────┘
```
