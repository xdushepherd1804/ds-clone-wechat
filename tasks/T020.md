## 目标

实现朋友圈前端页面，包含动态时间线、发布动态、图片预览、点赞评论交互。

## 功能需求

### 页面布局

```
朋友圈 (/moments)
├── 顶部封面图 (可自定义)
├── 用户头像 + 昵称
└── 动态列表
    └── 动态卡片
        ├── 发布者头像 + 昵称
        ├── 文字内容 (超过 6 行折叠)
        ├── 图片九宫格 (1~9 张)
        │   └── 1张: 大图, 2张: 双列, 3张+: 三列
        ├── 位置信息 (可选)
        ├── 时间 (x分钟前/x天前)
        ├── 操作栏: [点赞] [评论]
        ├── 点赞列表 (前N个点赞者头像)
        └── 评论区 (前2条，更多折叠)
```

### 发布动态

```
发布页 (/moments/new)
├── 文本输入区 (多行，placeholder: "这一刻的想法...")
├── 图片选择区 (从相册/拍照，最多9张)
│   └── 图片网格预览 + 删除按钮
├── 位置选择 (可选)
├── 可见性选择 (公开/好友可见/私密)
└── 发布按钮
```

### 交互

- 下拉刷新
- 上拉加载更多
- 点击图片全屏预览 (左右滑动)
- 双击动态卡片点赞
- 点赞按钮动画
- 评论弹出输入框
- 长按评论删除 (自己的评论)
