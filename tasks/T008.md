## 目标

实现消息收发、存储、已读回执、会话管理、离线消息等核心 IM 能力。

## 功能需求

### API 接口

```
POST   /api/messages/send          - 发送消息
GET    /api/messages/history       - 获取历史消息 (分页)
GET    /api/messages/conversations - 获取会话列表
PUT    /api/messages/read/:conv_id - 标记会话已读
DELETE /api/messages/:msg_id       - 撤回消息 (2分钟内)
GET    /api/messages/offline       - 拉取离线消息
```

### 消息类型

- TEXT: 文本消息
- IMAGE: 图片消息 (含缩略图)
- VOICE: 语音消息 (含时长)
- VIDEO: 视频消息
- FILE: 文件消息 (含文件名、大小)
- SYSTEM: 系统消息 (加群、退群等)
- LOCATION: 位置消息

### 消息流程

```
发送流程:
  Sender → WS Gateway → Message Service → 校验 → 存 MongoDB
    → 写入收件箱 (Receiver's message_box)
    → 通过 WS Gateway 推送给 Receiver
    → 返回 ACK 给 Sender

已读回执:
  Receiver → WS Gateway → Message Service → 更新 message_box.is_read
    → 推送已读状态给 Sender
```

### 会话管理

- 会话 ID 生成规则: `conv:{min(uid1,uid2)}:{max(uid1,uid2)}` (单聊)
- 群聊会话 ID: `conv:group:{group_id}`
- 会话列表按最后消息时间倒序
- 未读计数

### 消息存储 (MongoDB)

```
messages 集合索引:
  - { msg_id: 1 } unique
  - { to_uid: 1, created_at: -1 }  (单聊拉取)
  - { to_group_id: 1, created_at: -1 }  (群聊拉取)

message_boxes 集合索引:
  - { user_id: 1, conversation_id: 1, created_at: -1 }
  - { user_id: 1, is_read: 1 }
```
