## 目标

设计完整的数据库 Schema，涵盖用户、好友关系、消息、群组、朋友圈等核心实体。使用迁移工具管理版本。

## 数据库选型

- PostgreSQL: 用户、好友关系、群组、朋友圈等关系型数据
- MongoDB: 消息记录 (高写入、文档型)
- Redis: Session、缓存、在线状态、消息队列

## Schema 设计要点

### PostgreSQL 表

```
users                - 用户表
  id, username, password_hash, nickname, avatar, phone,
  status, last_seen_at, created_at, updated_at

contacts             - 好友关系表
  id, user_id, contact_id, remark, tags, status,
  created_at

groups               - 群组表
  id, name, avatar, owner_id, announcement,
  member_count, created_at

group_members        - 群成员表
  id, group_id, user_id, role, nickname_in_group,
  joined_at

moments              - 朋友圈动态
  id, user_id, content, images, location, visibility,
  created_at

moment_likes         - 点赞
  id, moment_id, user_id, created_at

moment_comments      - 评论
  id, moment_id, user_id, reply_to_id, content,
  created_at
```

### MongoDB 集合

```
messages
  _id, msg_id, from_uid, to_uid, to_group_id,
  msg_type (text/image/voice/video/file/system),
  content, file_url, thumbnail, status (sent/delivered/read),
  created_at, updated_at

message_boxes        - 用户消息箱 (收件箱模式)
  _id, user_id, msg_id, conversation_id, is_read,
  created_at
```

### Redis 键设计

```
session:{token}      - 用户 Session
user:online:{uid}    - 在线状态
ws:conn:{uid}        - WebSocket 连接信息
group:members:{gid}  - 群成员缓存
```
