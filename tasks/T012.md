## 目标

实现离线消息推送、应用内通知、消息队列集成、多设备同步。

## 功能需求

### 推送场景

| 场景 | 推送方式 | 内容 |
|------|---------|------|
| 新消息 | WS/APNs/FCM | 发送者昵称 + 消息摘要 |
| 好友申请 | WS/Push | "xxx 请求添加你为好友" |
| 群邀请 | WS/Push | "xxx 邀请你加入群聊" |
| @提醒 | WS/Push | "xxx 在群中@了你" |
| 系统通知 | WS/Push | 系统公告 |

### 多设备同步

- 同一用户多设备在线时，所有设备均收到消息
- 一台设备已读后，同步已读状态到其他设备
- 新设备登录后拉取最近 N 条消息

### 消息队列

- 使用 Redis Stream / BullMQ 作为消息队列
- 消息写入队列后异步推送给 WS Gateway
- 推送失败重试 3 次

### 推送优先级

```
HIGH:   新消息、音视频通话邀请
MEDIUM: 好友申请、群邀请
LOW:    朋友圈通知、系统公告
```
