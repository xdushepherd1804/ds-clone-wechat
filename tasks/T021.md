## 目标

实现基于 WebRTC 的一对一音视频通话功能，包含信令服务、通话 UI、通话状态管理。

## 技术选型

- WebRTC: 浏览器原生 API
- 信令: 通过 WebSocket 交换 SDP/ICE
- STUN/TURN: 使用公共 STUN 服务器 (开发阶段)
- 生产环境: LiveKit / Janus SFU

## 功能需求

### 信令流程

```
Caller → WS: call_request {callee_uid, call_type: audio|video}
Server → Callee: incoming_call {caller_uid, caller_name, call_type}
Callee → WS: call_accept 或 call_reject

# 接受后 WebRTC 协商
Caller → WS: offer_sdp {sdp}
Callee → WS: answer_sdp {sdp}
双方交换 ICE candidates
连接建立 → 开始通话

通话中:
  任一方 → WS: call_end → 对方收到 call_ended
```

### 通话 UI

```
来电界面 (被叫):
┌──────────────────────────────┐
│                              │
│     对方头像 + 昵称           │
│     来电邀请 (音频/视频)      │
│                              │
│   [拒绝]        [接听]      │
│                              │
└──────────────────────────────┘

通话中界面:
┌──────────────────────────────┐
│   对方视频画面 (大)          │
│                              │
│ ┌────────┐                  │
│ │自己画面│ (小窗)           │
│ └────────┘                  │
│                              │
│  [静音] [扬声器] [视频开关] │
│  [挂断]                     │
└──────────────────────────────┘
```

### 通话状态

- calling: 正在呼叫
- ringing: 响铃中
- connected: 已接通
- ended: 已结束
- rejected: 已拒绝
- timeout: 超时未接 (30s)

## 测试标准

1. 发起音频通话 → 对方收到来电 → 接听 → 正常通话
2. 拒绝通话 → 主叫方显示"已拒绝"
3. 30秒未接 → 主叫方显示"无人接听"
4. 通话中可切换静音/视频
5. 挂断后双方通话界面关闭
