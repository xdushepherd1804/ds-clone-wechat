## 目标

为核心服务编写单元测试，覆盖率达到 70%+。

## 测试范围

### 后端单元测试 (Jest/Vitest + Supertest)

```
server-auth/       - 注册、登录、Token 刷新、参数校验
server-message/    - 消息发送、存储、撤回、会话查询
server-contact/    - 好友申请、列表、搜索
server-group/      - 群创建、成员管理、权限
server-file/       - 上传、压缩、类型校验
server-moments/    - 发布、时间线、点赞评论
```

### 前端组件测试 (Vitest + React Testing Library)

```
Login/Register     - 表单校验、提交、错误提示
MessageBubble      - 各消息类型渲染
ChatInput          - 输入、发送、附件
ContactList        - 列表渲染、搜索过滤
```

### 测试工具

- 后端: Vitest / Jest
- 前端: Vitest + React Testing Library
- Mock: nock (HTTP), sinon (WS)
- 数据库: testcontainers / pg-mem
