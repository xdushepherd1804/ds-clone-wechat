## 目标

编写端到端服务集成测试，验证服务间协作正确性。

## 测试场景

### 消息流集成测试

```
1. 注册用户 A 和 B
2. A 添加 B 为好友 (申请→接受)
3. A 通过 WS 发送消息给 B
4. 验证 B 通过 WS 收到消息
5. B 标记已读
6. 验证已读回执推送给 A
```

### 群聊集成测试

```
1. 用户 A 创建群
2. A 邀请 B 和 C 加入
3. B 在群内发消息
4. 验证 A 和 C 都收到群消息
5. A 踢出 C
6. 验证 C 不再收到群消息
```

### 朋友圈集成测试

```
1. A 和 B 是好友
2. A 发布朋友圈 (friends 可见)
3. B 查看时间线，可见 A 的动态
4. B 点赞和评论
5. A 收到点赞和评论通知
```

### 文件上传集成测试

```
1. 上传图片 → 生成缩略图
2. 发送图片消息
3. 接收方查看图片和缩略图
```

### 测试环境

- Docker Compose 启动完整服务栈
- 独立测试数据库
- 测试数据清理
