## 目标

实现高性能 WebSocket 网关，管理用户长连接、心跳检测、消息路由、断线重连。

## 功能需求

### 连接管理

- WebSocket 握手时验证 JWT Token
- 维护 uid → connection 映射表
- 多设备同时在线支持 (同 uid 多个连接)
- 连接数限制 (单用户最多 5 个连接)

### 心跳机制

- 客户端每 30s 发送 Ping
- 服务端 60s 未收到 Ping 则断开
- 心跳超时不视为异常

### 消息路由

```
上行消息: Client → WS Gateway → 验证/解析 → Message Service
下行消息: Message Service → WS Gateway → 查找连接 → 推送给 Client
```

### 断线重连

- 客户端断线后指数退避重连
- 重连后补拉离线消息 (通过 HTTP API)
- 在线状态广播给好友

### 在线状态

- 连接建立: 设置 Redis `user:online:{uid}` = TTL 90s
- 心跳: 刷新 TTL
- 断线: TTL 过期自动清除

## 性能目标

- 支持 10,000+ 并发连接
- 连接建立 < 100ms
- 消息转发延迟 < 50ms

## 测试标准

1. 有效 Token 可建立 WebSocket 连接
2. 无效 Token 拒绝连接
3. 心跳超时断开连接
4. 同一用户多设备可同时在线
5. 消息正确路由到目标用户连接
